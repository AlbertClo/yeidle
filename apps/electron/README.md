# Yeidle (Electron)

The new desktop app: Electron with the shared TypeScript core in
`packages/core`. Replaces the NativePHP app in `apps/desktop`, which stays in
the repository for reference until this one reaches parity. See
[docs/loro-architecture.md](../../docs/loro-architecture.md).

```bash
npm install        # from the repository root
npm run dev -w @yeidle/electron
```
