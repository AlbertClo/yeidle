# Third-party theme palettes

Yeidle includes adapted color palettes from these MIT-licensed projects:

- [Catppuccin](https://github.com/catppuccin/catppuccin)
- [Gruvbox](https://github.com/morhetz/gruvbox)
- [Tokyo Night](https://github.com/tokyo-night/tokyo-night-vscode-theme)
- [Nord](https://github.com/nordtheme/nord)
- [Solarized](https://github.com/altercation/solarized)

Only a small set of colors is used and mapped to Yeidle's own semantic design
tokens. The original projects are not otherwise bundled or modified.
